# msc011_map

Map tiles for PiloOS mini apps (PiloMap): one PMTiles archive per country, cut from the daily planet build of Protomaps (https://maps.protomaps.com/builds/).

Map data © OpenStreetMap contributors (ODbL, https://www.openstreetmap.org/copyright). Basemap schema: Protomaps (BSD-3-Clause).

Files are release assets (tag `tiles`), read by byte range with the `pmtiles` JS library.
